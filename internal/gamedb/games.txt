#
# exe names can have conditions in braces:
#   javaw.exe{title:^Minecraft}      the main window title must match the regex
#   hl2.exe{path:\half-life 2\}      the full exe path must contain the text
#   godot*.exe                       simple glob
#
# Several exes on one line all count as the SAME game, so osu! stable and
# osu! lazer (both osu!.exe) share one playtime, and GTA V legacy + enhanced
# share one too.
